# Поток

Поток — торрент-клиент с русскоязычным интерфейсом. Он открывает локальную вкладку в браузере и скачивает файлы на диск через [anacrolix/torrent](https://github.com/anacrolix/torrent).

- Добавление magnet-ссылок и файлов `.torrent`, в том числе перетаскиванием в окно.
- Отображение прогресса, скорости скачивания и отдачи, числа пиров.
- Пауза, продолжение и удаление задания из очереди с сохранением скачанных файлов.
- Восстановление очереди и скачанных частей после перезапуска.
- У завершённых заданий продолжается раздача. Поставьте задание на паузу, чтобы остановить передачу данных.

## Готовые сборки

Скачайте архив для Windows или Linux (x64) и распакуйте его. В Windows запустите `Potok.exe`, в Linux — `./potok` из папки архива. [Скачать последнюю версию](https://github.com/Bediver32/Torrent/releases/latest)

## Сборка из исходников

Для сборки нужен [Go 1.27 или новее](https://go.dev/dl/).

```sh
go build -trimpath -o potok .
./potok
```

В Windows соберите и запустите исполняемый файл в PowerShell.

```powershell
go build -trimpath -o potok.exe .
.\potok.exe
```

Откроется локальная вкладка по адресу `http://127.0.0.1:47685`. По умолчанию файлы хранятся в `Downloads/Potok` внутри домашней папки. Каждая раздача получает отдельную подпапку. Чтобы выбрать другую папку, запустите приложение с параметром `-downloads "путь-к-папке"`.

Клиент работает в фоне, пока открыта программа. Кнопка **Завершить работу** в боковом меню сохраняет очередь и выключает клиент. При следующем запуске активные задания возобновляются автоматически.

## Использованные библиотеки

Движок [anacrolix/torrent](https://github.com/anacrolix/torrent/tree/c021e79b4ccf3a8edbe18d7131678396be14529e) распространяется по лицензии MPL 2.0. Для блокировки файла очереди используется [gofrs/flock](https://github.com/gofrs/flock).
